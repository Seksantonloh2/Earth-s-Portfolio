# Earth's Portfolio

Portfolio website for **Tanachok Aunpak** — graphic designer and video creator (Thai).

Static site, no build step. Open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).

## Pages
- `index.html` — home
- `work.html` — all 37 graphic pieces with brand/type filters and a lightbox
- `eitanic.html`, `sesante.html`, `tinted.html`, `phuriphat.html` — case studies
- `video.html` — 17 videos (play on Google Drive)
- `about.html` — services, process, KOFICE award
- `contact.html` — brief form (builds a message to copy; no server yet)

## Structure
- `assets/style.css` — shared styles (Inter Display / Anuphan, accent `#F20202`)
- `assets/site.js` — reveals, count-ups, menu, page transitions, filters, lightbox, form
- `img/` — artwork and video thumbnails (WebP)
